# Sorteio de Fim de Ano · Trilha

Sorteio de brindes para telão: suba a planilha de participantes, defina os brindes e as quantidades e sorteie todo mundo de uma vez.

Acesse: https://trilhagestao.github.io/sorteio/

- Aba **Teste**: 53 nomes de exemplo, nada é salvo.
- Aba **Meu sorteio**: sua lista e seus brindes, salvos só no seu navegador.

Arquivo único (`index.html`), funciona offline. Fonte Lilita One sob licença SIL Open Font License 1.1.
